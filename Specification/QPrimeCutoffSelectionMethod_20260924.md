# Q' 판정 기준값 선정 방법론

- 작성일: 2026-09-24
- 적용 대상: QSimEx 시뮬레이션 기반 Q' 판정 기준값 제안
- 관련 기준 문서: `DesignSpec_20260922.md`, `ImplementationPlan_20260924.md`
- 상태: 방법론 초안

## 1. 목적

이 문서는 시추공 Q'(`Q'_BH`)만으로 굴착 여부를 판단할 때 사용할 하한·상한 기준값을 시뮬레이션 결과에서 제안하는 방법을 정의한다.

실제 운영 판정에서는 다음 원칙을 따른다.

```text
Q'_BH < Q'_lowerbound
    -> 굴착 보류·생략 후보

Q'_lowerbound <= Q'_BH < Q'_upperbound
    -> 불확실 구간·추가 검토

Q'_BH >= Q'_upperbound
    -> 굴착 진행 후보
```

`Q'_face`는 실제 운영 시점의 입력이 아니다. 동일한 시뮬레이션 domain에 터널·굴진면
조건을 적용한 **가상굴착 후** 얻은 참조 결과이며, `Q'_BH` 기준값 후보의 적절성을
평가하는 데 사용한다. 실제굴착은 현장에서 암반을 실제로 굴착한 뒤 관측·조사·계측을
수행하는 별도 절차이다. 이 문서의 가상굴착 참조값은 실제굴착 결과나 처분 적합성
판정 그 자체를 의미하지 않는다.

## 2. 프로파일의 정의

시뮬레이션 참조지표를 하나의 종합점수로 합치지 않는다. 각 참조지표를 독립적인 프로파일로 유지한다.

시추공 Q' 값 `q`에 대해 프로파일 `P_j(q)`를 다음과 같이 정의한다.

$$
P_j(q) =
\text{Q'_BH가 q인 시뮬레이션 표본에서 관찰된 j번째 참조지표의 분포}
$$

가능한 프로파일의 예시는 다음과 같다.

- `P_face`: `Q'_face`의 중앙값, 분위수, 변동폭
- `P_intersection`: 처분공·굴진면과 절리의 유효 교차 관련 지표
- `P_density`: 절리 밀도·빈도 관련 지표
- `P_orientation`: 절리 방향성·교차각 관련 지표
- `P_compatibility`: EFPC 또는 독립 처분 적합성 평가가 제공하는 결과

프로파일은 단일 평균값이 아니다. 최소한 중앙값과 분위수 범위, domain별 분포를 함께 보존한다.

## 3. 프로파일 상태

각 프로파일을 새로운 점수로 변환하지 않고, Q' 위치별 상태로 표현한다.

$$
S_j(q) \in \{PR, TR, POST\}
$$

- `PR` (`pre-change`): 의미 있는 변화가 시작되기 전의 영역
- `TR` (`transition`): 프로파일 값이 변하거나 domain 간 결과가 혼재하는 영역
- `POST` (`post-change stable`): 변화 이후 인접 구간의 변화가 작고 안정된 영역

이 상태명은 처분 적합·부적합을 의미하지 않는다. 처분 적합·부적합은 EFPC 또는
향후 연결되는 독립 평가 adapter가 제공하는 별도 공학적 결과로 정의한다. 해당
평가가 연결되기 전에는 이 상태만으로 실제굴착의 안전성이나 처분 적합성을 주장하지
않는다.

위험 지표처럼 값이 낮을수록 양호한 지표는 상태 방향을 반대로 해석하되, 상태 의미는 모든 프로파일에서 동일하게 유지한다.

프로파일별 상태 집합은 다음과 같다.

$$
PR_j = \{q : S_j(q)=PR\}
$$

$$
TR_j = \{q : S_j(q)=TR\}
$$

$$
POST_j = \{q : S_j(q)=POST\}
$$

상태는 단일 표본의 값으로 정하지 않는다. 로그 Q' 구간별 분포, 인접 구간 변화, domain 반복성, 변동폭을 함께 사용하여 판단한다.

## 4. 프로파일 결합 함수

프로파일을 가중평균하거나 새로운 종합지수로 합치지 않는다. 모든 핵심 프로파일이 동시에 지지하는 영역을 교집합으로 구한다.

공통 PR 영역:

$$
PR_{common} = \bigcap_{j=1}^{m} PR_j
$$

공통 POST 영역:

$$
POST_{common} = \bigcap_{j=1}^{m} POST_j
$$

기준값 제안 함수는 다음과 같다.

$$
 f(P_1, \ldots, P_m) =
 \begin{cases}
 (L,U), & PR_{common}\neq\varnothing,\;POST_{common}\neq\varnothing,\;L<U \\
 \text{not identifiable}, & \text{그 외}
 \end{cases}
$$

여기서:

$$
L = \sup PR_{common}
$$

$$
U = \inf POST_{common}
$$

따라서 `L`은 공통 PR 영역의 끝이고, `U`는 공통 POST 영역의 시작이다. `[L,U)`가 프로파일 변화·불일치 영역이다.

## 5. 이산 후보값에서의 적용

초기 탐색 후보값은 설정 파일의 로그 균등 기준값을 사용한다. 예를 들어 `0.1~400`을 로그 공간 10구간으로 나누면 11개 기준값이 생성된다.

각 후보 구간에서 다음을 기록한다.

- `Q'_BH` 표본수
- `Q'_face` 중앙값과 분위수 범위
- 절리 교차·밀도·방향성 지표의 분포
- domain별 결과와 변동성
- 인접 후보 구간과의 변화 방향
- 안정 상태 여부

이산 후보값에서는 `sup`와 `inf`를 후보값 중 마지막·첫 번째 값으로 해석한다.

## 6. 예시

| 프로파일       | 변화 시작 | 안정 시작 |
| -------------- | --------: | --------: |
| `Q'_face`      |       2.8 |       6.3 |
| 절리 교차 위험 |       1.2 |       8.0 |
| 방향성         |       2.8 |       6.3 |

공통 PR 영역은 모든 프로파일에서 변화 전 상태가 겹치는 구간이다.

$$
L = \min(2.8, 1.2, 2.8) = 1.2
$$

공통 POST 영역은 모든 프로파일이 변화 후 안정 상태에 들어간 뒤의 구간이다.

$$
U = \max(6.3, 8.0, 6.3) = 8.0
$$

따라서 잠정 가이드는 다음과 같다.

```text
Q'_BH < 1.2   -> 공통 PR 영역, 보류·생략 후보
1.2 <= Q'_BH < 8.0 -> 변화·불확실 영역
Q'_BH >= 8.0  -> 공통 POST 영역, 굴착 후보
```

## 7. 기준값을 제시하지 않는 조건

다음 중 하나라도 해당하면 기준값을 숫자로 확정하지 않는다.

- 공통 PR 영역이 형성되지 않음
- 공통 POST 영역이 형성되지 않음
- 프로파일 간 변화 방향이 서로 반대임
- domain별 결과가 반복되지 않음
- 변화 영역이 후보 전체를 차지함
- `L >= U`
- 결측 또는 표본 부족으로 프로파일 상태를 판단할 수 없음

이 경우 결과는 다음처럼 기록한다.

```text
Q' 단독 기준값 산출 불가
```

이는 분석 실패가 아니라, 현재 시뮬레이션 자료만으로 안정적인 Q' 기준값을 식별할 수 없다는 결과다.

## 8. 정책값과 가중치에 대한 원칙

이 방법론에서는 기준값 산출을 위해 다음을 새로 도입하지 않는다.

- 프로파일별 임의 가중치
- 프로파일을 합산한 새로운 종합지수
- `Q'_face` 하나를 특정 값으로 자른 단일 정답 라벨
- 사전에 승인되지 않은 정책 허용치

대신 각 프로파일의 원래 분포와 변화 구간을 보존하고, 모든 핵심 프로파일의 공통 영역만 기준값 제안에 사용한다.

## 9. 해석 범위

이 방법으로 얻는 `L`, `U`는 가상굴착 참조 프로파일에 기반한 시뮬레이션 잠정
가이드다. 실제 현장 안전이나 처분 적합·부적합을 자동 보증하지 않는다. EFPC가
완성되거나 독립 평가 adapter가 연결되면 `P_compatibility` 프로파일과 처분 적합성
결과를 추가하여, 동일한 결합 함수와 별도 검증 절차로 잠정 기준값을 재검증한다.
