# `table2` — 의미과 용도

의미

- 민감도/세부 분석 표로 사용되는 표입니다. 경우에 따라 밀도·방향성·임계치 구간별 성능(예: 검출률, false rate)을 분해하여 제시합니다.

구성/생성

- 원 데이터는 `borehole_rows`/`face_rows`/`summary_rows` 등에서 가져오며, `ResearchReporter` 또는 분석 스크립트에서 그룹별 집계(그룹핑 및 요약 통계)를 수행해 생성합니다.

용도

- 하위 그룹(예: 밀집/희박, 특정 Jv 범위 등)별 성능 차이를 보여주기 위한 상세 분석표.
