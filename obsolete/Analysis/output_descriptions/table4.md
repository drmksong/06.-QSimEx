# `table4` — 의미과 용도

### 요약

1. 의미

- 베이지안 후행 확률 기반 의사결정 표입니다. 관찰(예: 보어홀/면 관측)에 대해 사후확률(해당 구간이 좋음/나쁨), 각 행동(Excavate/Skip)의 기대손실(expected loss), 그리고 비용 기반으로 권장되는 행동을 보여줍니다.

2. 핵심 항목

- 관찰 식별자(케이스·샘플)
- Prior / Likelihood / Posterior: 베이지안 업데이트 구성 요소
- Expected Loss: `cost_fp * P(no resource | obs)` 등으로 계산된 기대손실(예: Excavation vs Skip)
- Recommended Decision: 기대손실이 작은 쪽 선택

3. 생성 코드(대표)

- 가능성(라익리후드) 계산: `src/core/decision_test.py::DecisionUsefulnessTester.get_bayesian_likelihoods()`
- 베이지안 업데이트: `src/core/bayesian_update.py::bayesian_update_binary()`
- 기대손실 및 권장결정: `src/core/decision_test.py` 및 `src/core/reporting.py`의 리포팅 로직

4. 주의사항

- likelihood 추정(예: 민감도/특이도 계산)이 데이터의 분포나 임계치 설정에 민감하여, 관측이 편향되어 있으면(예: 면이 모두 양성으로 분류되는 경우) 표가 균일해질 수 있습니다. 이런 경우 경고 표시나 다른 추정 방법(풀링, 연속 모델 등) 고려가 필요합니다.

5. 용도

- 비용을 고려한 의사결정 논의 및 정책 수립(예: 어느 관측에서 시공을 권장할지)에 사용됩니다.

### 우도(민감도/특이도) 추정 — 현장용 가이드

1. 기본 개념

- 민감도(sensitivity, `sens`) = P(obs | good) = 관측이 나올 확률이 "좋음(good)" 상태에서 얼마나 잘 관찰되는지.
- 특이도(specificity, `spec`) = P(obs | bad) = 관측이 나올 확률이 "나쁨(bad)" 상태에서 얼마나 잘 배제되는지.

2. 카운트 기반 추정(가장 직관적)

- 과거 집계에서 `TP`(좋음인데 관찰 양성), `FN`(좋음인데 관찰 음성), `TN`, `FP`를 셉니다.
- 민감도: `sens = TP / (TP + FN)`
- 특이도: `spec = TN / (TN + FP)`

3. 소규모 표본 보정(라플라스 스무딩)

- 표본이 적거나 0 카운트가 나올 때는 단순 비율이 불안정합니다. add-one(라플라스) 스무딩을 권장:
  - `sens = (TP + 1) / (TP + FN + 2)`
  - `spec = (TN + 1) / (TN + FP + 2)`

4. 그룹 풀링 및 계층적 접근

- 관측별 데이터가 부족하면 유사한 조건(예: 같은 암종·밀도·스캔 방법)을 묶어 풀링합니다. 계층적 베이지안 모델을 사용하면 개별 관측과 전체 풀의 정보를 함께 반영할 수 있습니다.

5. 연속형 관측을 이용한 방법(우도 함수를 직접 추정)

- Q'나 RQD 같은 연속형 관측값을 그대로 사용하려면 관측 분포 `P(obs | good)`과 `P(obs | bad)`를 따로 모델링합니다.
  - 방법 A: 관측값을 클래스별로 분리해 KDE(커널밀도추정)로 `P(x|good)`/`P(x|bad)`를 추정.
  - 방법 B: 로지스틱 회귀로 `P(good | x)`를 직접 학습한 뒤 Bayes 역산을 통해 `P(x|good)`에 해당하는 우도를 유도(또는 바로 posterior 사용).

6. 불확실성 전파(현장 권고용)

- 민감도/특이도 추정 자체에 불확실성이 있으므로, 단일 포인트 posterior 대신 Monte Carlo(예: Beta 분포로 sens/spec 샘플링)를 사용해 posterior 분포와 기대손실 분포를 얻는 것이 권장됩니다.
  - 예: `sens ~ Beta(TP+1, FN+1)`, `spec ~ Beta(TN+1, FP+1)`로 샘플을 생성하고 각 샘플에 대해 posterior 및 기대손실을 계산하여 결정의 안정성을 평가.

7. 실무적 절차(현장 요약)

- 1. 가능한 과거 데이터에서 `TP/FN/TN/FP` 집계(없으면 가장 유사한 사례를 찾음).
- 2. 라플라스 스무딩 적용하여 `sens`/`spec` 계산.
- 3. Prior(면 평가), 비용(`cost_fp`, `cost_fn`) 입력.
- 4. Table 4의 행(각 관찰)에 대해 posterior 계산 및 기대손실 산출.
- 5. 불확실성이 큰 경우(샘플수 작음)에는 Monte Carlo로 안정성 확인 또는 보수적 규칙(예: 추가 시추 권고).

8. 간단한 수치 예시

- 과거 집계: `TP=8`, `FN=2`, `TN=6`, `FP=4` → 라플라스 없이
  - `sens = 8/(8+2) = 0.8`
  - `spec = 6/(6+4) = 0.6`
- 위 수치를 예시(문서 앞의 사례)처럼 Prior=0.3, cost_fp=1, cost_fn=5에 적용하면 Posterior≈0.4615, 기대손실(Excavate)≈0.54, (Skip)≈2.31 → Excavation 권장.

9. 경고 및 권장사항

- 관측별 `TP/FN/TN/FP` 집계는 실제로 보어홀(ground truth)과 면(관측)의 매칭에서 도출됩니다. 이 매칭 기준(예: 거리, 시간, 동일 위치 판단)은 표 추정 결과에 직접적 영향을 미칩니다.
- 데이터가 희소하면 풀링 또는 외부 데이터(문헌) 사용을 권장합니다. 또한 Table 4 출력에 "우도 불안정" 표시를 추가해 사용자가 해석 시 주의할 수 있도록 하세요.

참고 코드

- `src/core/decision_test.py`와 `src/core/bayesian_update.py`에서 우도/사후 계산 흐름을 확인할 수 있습니다. 필요하면 작은 분석 스크립트로 CSV를 읽어 `TP/FN/TN/FP` 집계를 자동 계산해 드리겠습니다.

현장 활용 예시

- 상황: 현장에서 보어홀 검사 결과 `RQD_bh_mean = 45`(보수적 중간값)이고, 굴진면(현장 관찰)으로부터 사전 평가로 해당 면의 양호 확률을 `Prior = 0.3`으로 추정했다고 가정합니다. 비용은 `cost_fp = 1.0`(잘못 굴착한 비용)과 `cost_fn = 5.0`(굴착을 건너뛰어 발생하는 손실)로 설정되어 있습니다.

- 단계 1 — 관찰의 likelihood 확보: Table 4는 관찰별로 민감도(`sens = P(obs|good)`)와 특이도(`spec = P(obs|bad)`) 또는 이와 동등한 likelihood 항목을 포함합니다. 예를 들어 해당 관찰에서 과거 집계로 `sens = 0.8`, `spec = 0.6`이 추정되었다면 다음을 사용합니다.

- 단계 2 — 베이지안 업데이트 (이항 케이스):
  - Prior = 0.3
  - Likelihood ratio 적용: Posterior = P(good|obs) = normalize( Prior _ sens , (1-Prior) _ (1-spec) )
  - 수치 예시: Numerator = 0.3 _ 0.8 = 0.24; Denominator (evidence) = 0.24 + 0.7 _ 0.4 = 0.24 + 0.28 = 0.52 → Posterior ≈ 0.4615

- 단계 3 — 기대손실 계산:
  - Excavation(굴착) 기대손실 = cost*fp * P(bad | obs) = 1.0 \_ (1 - Posterior) = 1.0 \* 0.5385 ≈ 0.5385
  - Skip(건너뛰기) 기대손실 = cost*fn * P(good | obs) = 5.0 \_ 0.4615 ≈ 2.3075

- 단계 4 — 권장 행동: 기대손실이 작은 쪽을 선택합니다. 위 예시에서는 Excavation의 기대손실(≈0.54)이 더 작으므로 "Excavate" 권장.

- 해석 팁:
  - 동일한 관찰에 대해 Prior 값을 바꿔 민감도(예: 보수적/관대) 상황을 테스트하면 권장 행동이 어떻게 변하는지 볼 수 있습니다.
  - `p_threshold = cost_fp / (cost_fp + cost_fn)` 공식을 사용하면 임계 사전확률 범위를 빨리 확인할 수 있습니다. 위 비용값의 경우 `p_threshold = 1 / (1+5) = 0.1667`로, Prior가 이보다 크면 일반적으로 굴착 쪽에 유리합니다(단, likelihood에 따라 달라질 수 있음).
  - Table 4의 `sens`/`spec` 추정이 불안정하면(데이터 부족 또는 편향) 사후확률과 결정이 신뢰할 수 없으니, 경고표시나 보수적 정책(예: 더 높은 비용 가정 또는 추가 검증)을 고려하세요.

위 예시는 `table4`의 각 행을 어떻게 읽고 실제 굴착 결정을 도출할지 보여줍니다. 문서의 다른 섹션에서 `sens`/`spec` 추출 방법(집계, 라플라스 스무딩, 풀링)을 참고해 현장 데이터에 맞게 조정하세요.

우도는 과거 관측의 누적 결과입니다 — 간단한 설명

- 요점: `sens`/`spec`는 과거 사례에서 관찰(검사 결과)과 실제 결과(굴착 후 확인된 상태)를 비교한 경험적 비율입니다. 이 말은, 동일한 검사와 조건에서 과거에 몇 번의 시도가 있었는지에 따라 우도의 신뢰도가 달라진다는 뜻입니다.

- 예시(직관적): 100개의 처분 터널을 건설해야 하는 상황에서 지금까지 10개의 유사 사례(완공 후 실제 상태 확인)가 있다면, 11번째 터널에 대한 판단을 내릴 때 이 10개의 사례에서 얻은 `TP/FN/TN/FP` 카운트를 사용해 `sens`/`spec`를 추정합니다. 이후 12번째, 13번째 사례가 쌓일수록 카운트가 누적되어 비율 추정의 표준오차가 줄어들고 우도의 신뢰도가 증가합니다.

- 추가 포인트: 표본이 작을 때는 라플라스 스무딩이나 풀링을 적용해 과도한 편향을 방지하세요. 또한 시간에 따른 환경 변화(장비 변경, 조사자 숙련도 향상, 지질 조건 차이 등)가 있을 수 있으므로 최근 데이터에 더 가중치를 주는 방법이 실무에서는 유용합니다.

### 구체 계산 예시 — 10개 누적 데이터(Laplace 스무딩 포함)

상황 요약:

- 누적 사례 수: 10
- 관측별 집계: Positive(관측 양성)=7, Negative(관측 음성)=3
- 실제 대조(굴착 후 확인) 분류: TP=5, FN=2, TN=2, FP=1

1. 단순 비율(스무딩 없이)

- 민감도: sens = TP / (TP + FN) = 5 / (5 + 2) = 5/7 ≈ 0.7142857
- 특이도: spec = TN / (TN + FP) = 2 / (2 + 1) = 2/3 ≈ 0.6666667

2. 라플라스(애드-원) 스무딩 적용

- 스무딩 식: sens = (TP + 1) / (TP + FN + 2); spec = (TN + 1) / (TN + FP + 2)
- 민감도(스무딩): sens = (5 + 1) / (7 + 2) = 6/9 = 0.6666667
- 특이도(스무딩): spec = (2 + 1) / (3 + 2) = 3/5 = 0.6

3. 라플라스 값의 불확실성 표기 (Beta 분포 관점)

- sens ~ Beta(TP+1, FN+1) = Beta(6, 3) → 평균 = 6/(6+3) = 0.6667
- spec ~ Beta(TN+1, FP+1) = Beta(3, 2) → 평균 = 3/(3+2) = 0.6
- Beta 분포를 통해 95% 신뢰구간을 계산하면 표본수 10에서는 폭이 비교적 넓어 불확실성이 큽니다.

4. Posterior 및 기대손실 계산(예시 prior/cost 적용)

- 가정: Prior = 0.3, cost_fp = 1.0, cost_fn = 5.0
- smoothed sens/spec 사용: sens = 0.6666667, spec = 0.6
- Posterior 계산(베이지안 이항 업데이트):
  - Numerator = Prior _ sens = 0.3 _ 0.6666667 = 0.2
  - Evidence = Numerator + (1 - Prior) _ (1 - spec) = 0.2 + 0.7 _ 0.4 = 0.2 + 0.28 = 0.48
  - Posterior = Numerator / Evidence = 0.2 / 0.48 ≈ 0.4166667
- 기대손실:
  - Excavation loss = cost*fp * P(bad | obs) = 1.0 \_ (1 - Posterior) = 0.5833333
  - Skip loss = cost*fn * P(good | obs) = 5.0 \_ Posterior = 2.0833335
- 권장 행동: Excavation (기대손실이 더 작음)

5. 실무적 해석

- 이 예시에서 10개의 누적 데이터로 얻은 smoothed 우도를 사용하면 Posterior가 약 0.42로 계산되어 굴착이 권장됩니다. 그러나 불확실성이 큰 편이므로(표본 n=10) Monte Carlo로 sens/spec를 Beta에서 샘플링해 Posterior 분포와 기대손실 분포를 확인하면 결정의 안정성을 평가할 수 있습니다.

6. 체크리스트(현장 작업자가 따를 항목)

- 과거 사례의 `TP/FN/TN/FP` 집계를 확인한다.
- 라플라스 스무딩을 적용해 sens/spec를 계산한다(특히 작은 표본일 때).
- Prior와 비용을 명시하고 Posterior 및 기대손실을 계산한다.
- 불확실성이 크면 추가 시추 또는 보수적 의사결정 규칙 적용.

위 계산은 Table 4의 한 행(관찰)에 대해 작업자가 직접 따라해볼 수 있는 완전한 예시입니다. 필요하면 이 계산을 자동으로 수행하는 작은 스크립트를 `tools/`에 만들어 드리겠습니다.

### 사전확률(Prior) 계산 — 실무 가이드

- 사전확률의 의미: 사전확률은 관찰을 보기 전(관측 이전)에 해당 위치가 `good`(양호)일 확률의 추정치입니다. 이는 이론적 값이 아니라 과거 사례·전문가 판단·현장 평가(예: 면 스코어)로부터 도출됩니다.

- 실무적 추정원(권장, 단순화)

1. 건설 초기 조사에서 산출한 '양호 등급 비율' 사용(권장):


    - 예: 굴착 초기 단계에서 채점한 결과 중 1·2등급(또는 현장 규정상 '양호'로 분류된 등급)이 전체에서 차지하는 비율을 Prior로 사용합니다. (예: 초기 10개 굴착 중 7개가 양호하면 Prior = 0.7)

2. 전문가 판단과의 단순 결합(현장 실무용):


    - 전문가 점수(expert ∈ [0,1])와 경험적 비율(empirical)을 가중평균으로 결합: `Prior = w * empirical + (1-w) * expert` (w는 현장 정책으로 정함).

3. 데이터가 부족할 때의 보완: 유사 지역·유사 공법의 통계(pooling)이나 문헌 값을 활용하되, 가능한 한 동일한 측정값을 Prior와 Likelihood에 동시에 사용하지 않도록 주의합니다.
4. 간단한 원칙: Prior는 "관측 이전"의 배경 정보(초기조사·지역통계·전문가평가 등)를 의미하도록 제한하고, Q'/Q 같은 동일한 관측값은 가능하면 Likelihood(관찰) 쪽에서만 사용하세요. 중복 사용은 결과를 과도하게 확신하게 만들 수 있습니다.

- 간단한 수치 예시(경험적):
  - 과거 유사 관측 n=50, good_count=15 → Prior_empirical = 15/50 = 0.3
  - 전문가가 0.5를 제시하고 융합 가중치 w=0.6일 때 Prior_combined = 0.6*0.3 + 0.4*0.5 = 0.18 + 0.2 = 0.38

- 불확실성 모델링(권장):
  - Prior도 확률적 불확실성을 가집니다. 경험적 비율을 Beta 분포로 표현: Prior ~ Beta(good_count+1, bad_count+1). 이 분포에서 샘플을 뽑아 posterior 및 기대손실의 분포를 계산하면 결정의 안정성을 평가할 수 있습니다.

- 실무 체크리스트(사전확률 설정)
  1. 사용 가능한 과거 데이터(유사성 기준)를 먼저 확인한다.
  2. 데이터가 충분하면 경험적 비율을 기본 prior으로 사용하되 Beta 불확실성을 함께 표시한다.
  3. 데이터가 부족하면 전문가 의견을 보강하거나 인근·유사 사이트 풀링을 사용한다.
  4. 관찰값(Q'/RQD 등)에 기반한 캘리브레이션이 가능하면 그 매핑을 문서화하여 일관되게 사용한다.
